คัดลอกโค้ดติดตั้งระบบ

กดปุ่ม "คัดลอก" ทีละไฟล์ แล้ววางใน Google Apps Script ตามลำดับ

⚠️ เปิด Apps Script จาก Google Sheet ของศูนย์ → Extensions → Apps Script เท่านั้น — ไฟล์ .gs ต้องมีแค่ไฟล์เดียว ที่วางโค้ด Code.gs ทั้งก้อน ลบไฟล์ .gs อื่นทิ้ง (เช่น Config, Db, Services, Line, Setup, WebApp) ส่วนไฟล์ HTML ที่เคยสร้างไว้ จะเก็บหรือลบก็ได้ ระบบใช้หน้าเว็บที่ฝังใน Code.gs

✅ วางครบแล้ว ทำต่อ

  1. กด 💾 บันทึก — dropdown ข้างปุ่ม ▶ Run ต้องมี doGet
  2. เลือกฟังก์ชัน setupSheets → ▶ Run → อนุญาตสิทธิ์ (Advanced → Go to… → Allow)
  3. ⚙️ Project Settings → Script Properties → เพิ่ม ADMIN_PIN (รหัสเข้าหน้าผู้จัดการ)
  4. Deploy → New deployment → Web app → Execute as: Me · Who has access: Anyone → Deploy
  5. คัดลอกลิงก์ที่ลงท้าย /exec ไปใช้งาน
