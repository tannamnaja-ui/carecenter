# ศูนย์ดวงใจกตัญญู — ระบบบริหารงานดูแลผู้ป่วย

> ดูแลด้วยใจ ซื่อสัตย์ ปลอดภัย วางใจดั่งญาติสนิท

ระบบนี้ใช้ Google Apps Script ทำงานบน Google Sheet เดิมของศูนย์ (7 แผ่นงาน) ประกอบด้วย 3 หน้าเว็บ:

| หน้า | ลิงก์ | ใครใช้ |
|---|---|---|
| หน้าผู้จัดการศูนย์ | `.../exec` | ผู้จัดการ (เข้าด้วย PIN) |
| ฟอร์มจองบริการ | `.../exec?page=จองบริการ` (ลิงก์เดิม `?page=book` ยังใช้ได้) | ลูกค้า / ญาติ |
| ฟอร์มยื่นใบลา | `.../exec?page=ยื่นใบลา` (ลิงก์เดิม `?page=leave` ยังใช้ได้) | ผู้รับจ้าง (ยืนยันตัวตนด้วยรหัส + เบอร์โทร 4 ตัวท้าย) |

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `Config.gs` | ค่าตั้งต้น ชื่อแผ่นงาน สถานะ และโครงสร้างคอลัมน์ |
| `Db.gs` | อ่าน/เขียนชีต (อ่านหัวคอลัมน์จากแถว 3 และไม่เขียนทับเซลล์ที่มีสูตร) |
| `Services.gs` | ตรรกะหลัก: คัดคน, กันจองงานชนกัน, ดึงราคาอัตโนมัติ, ตรวจการชำระเงิน, ใบลา |
| `Line.gs` | แจ้งเตือน LINE, เตือนล่วงหน้า 24 ชม., webhook ลงทะเบียน LINE ของผู้รับจ้าง |
| `Setup.gs` | เมนูในชีต, ติดตั้งโครงสร้าง, dropdown, สีเตือน, ทริกเกอร์ |
| `WebApp.gs` | เลือกหน้าเว็บที่จะแสดง |
| `Index.html` / `Public.html` / `Styles.html` | หน้าเว็บ |
| `appsscript.json` | Manifest (เขตเวลา Asia/Bangkok) |

## ขั้นตอนติดตั้ง

### 1. นำโค้ดเข้า Google Sheet
1. เปิด Google Sheet ของศูนย์ แล้วไปที่ **Extensions → Apps Script**
2. สร้างไฟล์ตามรายชื่อข้างบน แล้วคัดลอกเนื้อหาจากโปรเจกต์นี้ไปวาง
   - ไฟล์ `.gs`: กด **+ → Script** และตั้งชื่อโดยไม่ต้องพิมพ์ `.gs`
   - ไฟล์ `.html`: กด **+ → HTML** และตั้งชื่อ `Index`, `Public`, `Styles`
   - `appsscript.json`: ไปที่ Project Settings แล้วติ๊ก *Show "appsscript.json"* จากนั้นวางทับ
   - หากใช้ [clasp](https://github.com/google/clasp) สามารถ `clasp push` ทั้งโฟลเดอร์ได้เลย
3. หากใช้ Sheet ไฟล์อื่น ให้แก้ `SPREADSHEET_ID` ใน `Config.gs`

### 2. ตั้งค่าลับ (Project Settings → Script Properties)
| Property | ค่า |
|---|---|
| `ADMIN_PIN` | รหัสเข้าหน้าผู้จัดการ (ควรยาว 6 ตัวขึ้นไป) |
| `LINE_CHANNEL_ACCESS_TOKEN` | Channel access token (long-lived) ของ LINE OA |
| `LINE_CENTER_TARGET_ID` | userId หรือ groupId ที่จะรับแจ้งเตือนของศูนย์ (ดูขั้นตอนที่ 5) |
| `SLIP_FOLDER_ID` | *(ไม่บังคับ)* ID โฟลเดอร์ Drive สำหรับเก็บสลิป หากไม่ใส่ ระบบจะสร้างให้เอง |

### 3. ติดตั้งโครงสร้างชีต
รีเฟรช Google Sheet แล้วจะมีเมนู **💗 ศูนย์ดวงใจกตัญญู** ขึ้นมา
- **1) ติดตั้ง/ตรวจสอบโครงสร้างแผ่นงาน**: ระบบตรวจทั้ง 7 แผ่นงาน แล้วเพิ่มคอลัมน์เสริมต่อท้ายตาราง ได้แก่ `line_user_id`, `required_skill`, `requires_car` (ไม่ลบหรือย้ายคอลัมน์เดิม และสูตรในแผ่น สรุปผล ยังใช้ได้) พร้อมใส่ dropdown สถานะและสีเตือน
- **2) เปิดแจ้งเตือนล่วงหน้า 24 ชม.**: สร้างทริกเกอร์ให้ระบบตรวจทุกชั่วโมง

### 4. Deploy เป็นเว็บแอป
**Deploy → New deployment → Web app**
- Execute as: **Me**
- Who has access: **Anyone** (ฟอร์มจองบริการและฟอร์มใบลาต้องเปิดได้โดยไม่ต้องล็อกอิน ส่วนหน้าผู้จัดการป้องกันด้วย PIN)

เมื่อ Deploy เสร็จแล้ว ดูลิงก์ทั้งหมดได้ที่เมนู **ลิงก์ระบบ** หรือแท็บ "ลิงก์ & LINE" ในหน้าผู้จัดการ

> หลังแก้โค้ดทุกครั้ง ให้กด **Deploy → Manage deployments → Edit → Version: New version** เพื่อให้ลิงก์เดิมใช้โค้ดใหม่

### 5. ตั้งค่า LINE (Messaging API)
> **LINE Notify ปิดให้บริการแล้ว (31 มี.ค. 2025)** ระบบนี้จึงใช้ LINE Official Account + Messaging API แทน

1. สร้าง LINE Official Account แล้วเปิดใช้ Messaging API ที่ [LINE Developers Console](https://developers.line.biz/)
2. ออก **Channel access token (long-lived)** แล้วนำไปใส่ใน `LINE_CHANNEL_ACCESS_TOKEN`
3. ตั้ง **Webhook URL** เป็นลิงก์เว็บแอป (`.../exec`) แล้วเปิด *Use webhook*
4. เชิญบอทเข้ากลุ่ม LINE ของทีมศูนย์ แล้วพิมพ์ `id` บอทจะตอบ groupId กลับมา ให้นำไปใส่ใน `LINE_CENTER_TARGET_ID`
5. เมนู **3) ทดสอบส่ง LINE ถึงศูนย์** ใช้ตรวจว่าการตั้งค่าใช้งานได้
6. ผู้รับจ้างแต่ละคนเพิ่มเพื่อน OA แล้วพิมพ์ `ลงทะเบียน WK-001 1234` (รหัสของตนตามด้วยเบอร์โทร 4 ตัวท้าย) เพื่อรับแจ้งเตือนงานส่วนตัว

## ฟังก์ชันตามข้อกำหนด

### 2.1 จับคู่งาน
- **คัดคนตามคุณสมบัติ**: ทุกครั้งที่เลือกบริการหรือวันเวลาในใบงาน ระบบจะแสดงเฉพาะคนที่ตรงทุกเงื่อนไขต่อไปนี้
  - ทักษะตรงกับงาน: ใช้ `required_skill` ของบริการ หากไม่ได้กำหนดไว้ จะเทียบ `skill_tags` กับชื่อบริการแทน เช่น "ส่ง รพ." ตรงกับ "รับ-ส่ง รพ. ด้วยรถผู้รับจ้าง"
  - `status` เป็น "พร้อมรับงาน"
  - ผลตรวจประวัติอาชญากรรม "ผ่าน" (ปิดเงื่อนไขนี้ได้ที่ `REQUIRE_POLICE_CHECK` ใน `Config.gs`)

  คนที่ถูกคัดออกจะแสดงพร้อมเหตุผล
- **เช็ครถส่วนตัว**: หากบริการมี `requires_car = TRUE` หรือชื่อบริการมีคำว่า "รถผู้รับจ้าง" ระบบจะคัดเฉพาะคนที่ `has_car = TRUE`
- **กันจองงานชนกัน**: ช่วงเวลาที่ทับกับใบงานอื่นของคนเดียวกัน (ไม่นับใบงานที่ยกเลิก) หรือทับกับวันลาจะถูกบล็อกทั้งตอนแสดงรายชื่อและตอนบันทึก ส่วนงานที่ต่อเวลากันพอดี เช่น ใบหนึ่งจบ 20:00 อีกใบเริ่ม 20:00 บันทึกได้

### 2.2 ความเสี่ยงและการเงิน
- **ราคาคงที่**: ระบบดึงยอดจากแผ่นงาน "บริการของศูนย์ทั้งหมด" (เดิมชื่อ Service_Catalog) ทางฝั่งเซิร์ฟเวอร์เสมอ แม้มีตัวเลขส่งมาจากหน้าเว็บก็จะไม่ถูกนำไปใช้ ใบงานเดิมยังคงราคา ณ วันที่เปิดใบงาน หากภายหลังมีการเปลี่ยนราคาบริการ
- **ตรวจการชำระก่อนเริ่มงาน**: ใบงานที่ยัง "รอชำระ" จะติดป้ายแดง **ห้ามปล่อยคน** และระบบจะ**ไม่ยอมให้**เปลี่ยนสถานะเป็น "กำลังปฏิบัติงาน" หรือ "เสร็จสิ้น" จนกว่าจะชำระ เมื่อบันทึกรับเงินครบยอด สถานะจะเปลี่ยนเป็น "ชำระแล้ว" ให้อัตโนมัติ
- เมื่อปิดงานเป็น "เสร็จสิ้น" ระบบจะสร้างรายการ "จ่ายให้คนทำงาน (รอโอน)" ให้อัตโนมัติ

### 2.3 แจ้งเตือน LINE
- ลูกค้าจองงานใหม่หรือมีการสร้างใบงาน → แจ้งศูนย์
- ผู้รับจ้างยื่นลา → แจ้งศูนย์ หากแจ้งล่วงหน้าน้อยกว่า 7 วันจะขึ้น 🔴 **แจ้งลากะทันหัน ผิดเงื่อนไขสัญญา** ทั้งใน LINE ในหน้าเว็บ และในชีต (สีแดง)
- ก่อนเริ่มงาน 24 ชม. → ส่งข้อความหาผู้รับจ้าง พร้อมที่อยู่ จุดสังเกต ข้อควรระวัง และเบอร์ญาติ หากผู้รับจ้างยังไม่ผูก LINE งานยังไม่ได้จัดคน หรือลูกค้ายังไม่ชำระ ระบบจะเตือนศูนย์แทน
- ระบบเตือนครั้งเดียวต่อใบงาน หากเลื่อนวันหรือเปลี่ยนคนทำงาน จะเตือนใหม่อีกครั้ง

### การลาและการจัดคนแทน
ในหน้าพิจารณาใบลา ระบบจะแสดงใบงานที่ได้รับผลกระทบ และรายชื่อคนที่ส่งไปแทนได้ (ตรวจทักษะ รถ สถานะ และเวลาชนให้แล้ว) เมื่อกดอนุมัติ ระบบจะย้ายใบงานไปให้คนแทนและส่ง LINE แจ้งคนแทนให้อัตโนมัติ

## ข้อควรรู้
- ข้อมูลเริ่มที่**แถว 4** (แถว 1 = ชื่อตาราง, แถว 2 = คำอธิบายภาษาไทย, แถว 3 = ชื่อฟิลด์) ห้ามเปลี่ยนชื่อฟิลด์ในแถว 3
- ระบบไม่เขียนทับเซลล์ที่มีสูตร เช่น VLOOKUP ในแผ่น ใบงาน หรือสูตร notice_days ในแผ่น ใบลา และไม่แตะคอลัมน์ที่ใช้ ARRAYFORMULA
- เบอร์โทรและเลขบัตรประชาชนถูกบันทึกเป็นข้อความ เพื่อไม่ให้เลข 0 ตัวหน้าหาย ระบบตรวจ checksum ของเลขบัตร 13 หลักด้วย
- Apps Script อ่าน header ของ webhook ไม่ได้ จึงตรวจลายเซ็น LINE ไม่ได้ การผูก LINE จึงต้องยืนยันด้วยเบอร์โทร 4 ตัวท้ายแทน
